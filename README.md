### 🧠 Como trabalho com IA

Uso agentes de codificação (**Claude Code**, **OpenAI Codex**, **Google Antigravity**) orquestrados em pipeline, cada um no papel onde rende mais — com subagentes especializados para produto, arquitetura, implementação e revisão:

```
protótipo UI/UX → PRD → TDD → implementação por agente → testes → revisão cruzada
```

Cada etapa é auditável antes de seguir para a próxima — a IA acelera, mas a decisão técnica continua sendo minha.
